Agent Skills: Anthropic übergibt den Standard an die Linux Foundation

Anthropic übergibt Agent Skills an die Linux Foundation: eine Million Skills, 280 Millionen Installationen, 70 Plattformen. Was sich ändert - und was nicht.

Anthropic hat am 22. Oktober angekündigt, Agent Skills - das offene Format, mit dem sich KI-Agenten spezialisiertes Wissen und Arbeitsabläufe beibringen lassen - an die Agentic AI Foundation (AAIF) zu übergeben [1]. Die AAIF ist eine Stiftung unter dem Dach der Linux Foundation, die Anthropic im vergangenen Jahr zusammen mit Block und OpenAI mitgegründet hat; bereits das Model Context Protocol (MCP) hatte Anthropic dort abgelegt [1].

Was genau übergeben wurde

Die Übergabe umfasst den Namen und das Logo von Agent Skills, die GitHub-Organisation und die Domain agentskills.io [1]. Wer den Standard nutzt oder daran mitarbeitet, muss dafür nicht Mitglied der AAIF werden [1]. Die AAIF soll dem Standard nach Anthropics Darstellung ein neutrales Zuhause geben und sicherstellen, dass die Community ein Mitspracherecht bei der Weiterentwicklung hat [1].

Was ein Skill ist

Ein Skill ist ein Ordner, der eine Datei namens SKILL.md enthält - darin steht, wie ein Agent eine bestimmte Aufgabe oder Domäne behandelt - plus optional Skripte und Referenzmaterial [1]. Entstanden ist das Format bei der Arbeit an Claude Code: Das Modell beherrschte allgemeine Wissensarbeit gut, ihm fehlte aber das prozedurale Wissen für konkrete Geschäftsaufgaben [1].

Nach dem Launch im Oktober 2025 veröffentlichten Entwickler binnen Wochen tausende Skills auf GitHub und schrieben Lader für Codex, Cursor und OpenCode. Im Dezember 2025 stellte Anthropic Agent Skills als offenen Standard unter eigener GitHub-Organisation und Domain, damit jeder Agent das Format nutzen kann [1]. Die Spezifikation liegt weiterhin öffentlich auf agentskills.io [3].

Die Verbreitung in Zahlen

Nach Angaben von Anthropic haben mehr als 70 Agenten-Plattformen Agent Skills integriert, darunter ChatGPT, Cursor, GitHub Copilot und VS Code [1]. Bislang wurde eine Million Skills veröffentlicht und knapp 280 Millionen installiert [1]. Diese Zahlen stammen vom Hersteller; eine unabhängige Prüfung gibt es nicht.

Wer den Standard jetzt pflegt

Gepflegt wird der Standard künftig von Entwicklern aus Anthropic, Google, OpenAI und weiteren Unternehmen - ausdrücklich als Einzelpersonen, nicht als Firmendelegierte. Lead Maintainers sind David Soria Parra und Mahesh Murag [1]. Als Roadmap schlägt Anthropic versionierte Releases, einen formalen Prozess für Änderungsvorschläge und Sicherheitsrichtlinien für alle vor, die Skills schreiben oder installieren [1]. Der Sicherheitspunkt ist nicht akademisch: Wer fremde Skills installiert, lädt Anweisungen und Skripte in den Kontext eines Agenten - ein klassischer Angriffsvektor im Umfeld von Prompt Injection.

Vier neue Projekte auf einen Schlag

Die Übergabe war Teil einer größeren Ankündigung der Linux Foundation: Die AAIF nahm gleich vier neue Projekte auf - neben Agent Skills noch Open Responses (beigesteuert von OpenAI), OpenEnv (Hugging Face) und OpenSandbox (Alibaba) [2]. Damit hostet die Stiftung in ihrem ersten Jahr zehn Projekte, nach drei zum Start im Dezember 2025 [2]. Bekanntgegeben wurde das auf der AGNTCon + MCPCon North America in San Jose [2].

Die vier neuen AAIF-Projekte im Überblick
Projekt und ZweckBeigesteuert vonQuelle
Agent Skills: offenes Format, mit dem Agenten neue Fähigkeiten und Domänenwissen ladenAnthropic[2]
Open Responses: anbieterübergreifende LLM-Schnittstelle auf Basis der OpenAI Responses API - gemeinsames Schema, Streaming-Events, erweiterbares ToolingOpenAI[2]
OpenEnv: offenes Framework für RL-Trainingsumgebungen als containerisierter Dienst mit MCP- und Gym-SchnittstellenHugging Face[2]
OpenSandbox: sichere Ausführungsumgebung für AgentenAlibaba[2]

Die vier Projekte decken laut Linux Foundation vier Schichten des Agenten-Stacks ab: wie Agenten neue Fähigkeiten bekommen, wie Anwendungen anbieterübergreifend mit Modellen sprechen, wie Agenten trainiert und evaluiert werden und wo sie sicher laufen [2]. Sie reihen sich neben die bisherigen Projekte ein - darunter das Agent2Agent-Protokoll (A2A), AGENTS.md, goose und MCP [2].

Einordnung: Das MCP-Muster wiederholt sich

Die Übergabe folgt demselben Muster wie beim Model Context Protocol: Ein einzelnes Unternehmen baut ein Format, das Format verbreitet sich über den eigenen Produktkontext hinaus, und sobald die Adoption breit genug ist, wandert die Governance in eine neutrale Stiftung [1]. Für Anwender ändert sich zunächst wenig: Der Standard bleibt offen, die Spezifikation öffentlich, und niemand muss der AAIF beitreten [1].

Spannend wird es bei der Roadmap: Versionierte Releases und ein formaler Proposal-Prozess sind bislang nur Vorschläge [1]. Ob die Stiftung es schafft, die Interessen der konkurrierenden Beiträger - Anthropic, OpenAI, Google, Alibaba, Hugging Face - in einem einzigen Standardisierungsprozess zu bündeln, wird sich erst zeigen. Dass OpenAI mit Open Responses gleichzeitig eine Spezifikation abgibt, die auf der eigenen Responses-API basiert [2], zeigt, wie eng offene Standards und Firmeninteressen hier beieinanderliegen.

Methode

Analyse auf Basis der Ankündigungen von Anthropic und der Linux Foundation sowie der Spezifikationsseite agentskills.io. Die genannten Verbreitungszahlen (integrierte Plattformen, veröffentlichte und installierte Skills) stammen von Anthropic und wurden nicht unabhängig geprüft.

Grenzen

Dieser Artikel basiert auf den öffentlichen Ankündigungen der beteiligten Organisationen. Wie sich die neue Governance in der Praxis entwickelt - etwa bei versionierten Releases und Sicherheitsrichtlinien -, ist zum Zeitpunkt der Veröffentlichung offen; die entsprechende Roadmap ist bislang nur ein Vorschlag [1].

Häufige Fragen

Was sind Agent Skills?

Ein Skill ist ein Ordner mit einer SKILL.md-Datei, die einem KI-Agenten eine bestimmte Aufgabe oder Domäne beibringt, plus optional Skripte und Referenzmaterial. Das Format stammt von Anthropic und wurde im Dezember 2025 als offener Standard veröffentlicht [1].

Was ändert sich durch die Übergabe an die AAIF?

Zunächst wenig: Der Standard bleibt offen, und Nutzer müssen nicht Mitglied der Agentic AI Foundation werden. Neu ist die neutrale Governance - die Weiterentwicklung liegt künftig bei Maintainers aus mehreren Unternehmen statt allein bei Anthropic [1].

Wer pflegt den Agent-Skills-Standard jetzt?

Entwickler aus Anthropic, Google, OpenAI und weiteren Unternehmen, ausdrücklich als Einzelpersonen. Lead Maintainers sind David Soria Parra und Mahesh Murag [1].

Was hat das mit MCP zu tun?

Anthropic hatte das Model Context Protocol (MCP) bereits zuvor an dieselbe Stiftung übergeben. Die AAIF wurde von Anthropic gemeinsam mit Block und OpenAI gegründet und beherbergt inzwischen zehn Projekte [1][2].

Kann ich eigene Skills schreiben?

Ja. Die Spezifikation ist öffentlich auf agentskills.io verfügbar; Beiträge zum Standard laufen über die GitHub-Organisation des Projekts [1][3].
