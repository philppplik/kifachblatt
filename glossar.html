Glossar: KI-Begriffe, kurz erklärt

Die wichtigsten Begriffe rund um Sprachmodelle und Agenten, in einem Satz erklärt.

Agent
Ein Sprachmodell, das in einer Schleife plant, Werkzeuge aufruft und Ergebnisse auswertet, bis ein Ziel erreicht ist. Mehr dazu →
Embedding
Eine Zahlenfolge, die die Bedeutung eines Textes beschreibt. Ähnliche Texte liegen nah beieinander. Grundlage der Bedeutungssuche bei RAG. Mehr dazu →
Evals
Feste Testmengen, mit denen Modelle, Prompts und Aufbauten vergleichbar bewertet werden. Mehr dazu →
Fine-Tuning
Nachtrainieren eines vorhandenen Modells mit eigenen Beispielen, um Stil oder Verhalten anzupassen.
Halluzination
Eine plausibel klingende, aber falsche oder erfundene Aussage eines Sprachmodells. Mehr dazu →
Inferenz
Das Ausführen eines trainierten Modells, also das Erzeugen von Antworten.
Kontextfenster
Die Textmenge, die ein Modell pro Anfrage gleichzeitig berücksichtigen kann. Mehr dazu →
MCP
Model Context Protocol, ein offener Standard, über den Programme Werkzeuge und Datenquellen für KI-Anwendungen bereitstellen.
Prompt
Die Eingabe an ein Sprachmodell: Frage, Anweisung und mitgegebenes Material.
Prompt-Caching
Zwischenspeichern eines wiederkehrenden Prompt-Anfangs, damit er günstiger und schneller verarbeitet wird. Mehr dazu →
RAG
Retrieval-Augmented Generation: Passende Textstücke werden vor der Antwort gesucht und dem Modell mitgegeben. Mehr dazu →
Token
Kleines Textstück, in dem Sprachmodelle rechnen und nach dem abgerechnet wird. Mehr dazu →
Werkzeugaufruf
Die Anforderung eines Modells, eine Funktion auszuführen, etwa Suche oder Dateizugriff. Ausgeführt wird sie vom umgebenden Programm. Mehr dazu →
